# JugaJug

This is a personal portfolio website created to allow clients and businesses to contact me for development projects. It presents my technical skills, services offered, and the technologies I work with, along with direct contact options.

You can visit the live website here: **https://www.jugajug.in**

The website acts as a simple project landing page where potential clients can review my capabilities and reach out through the contact form, email, or WhatsApp.

## Tech Stack

* HTML
* CSS
* JavaScript
* Font Awesome
* Google Fonts
* Formspree (for contact form submission)

## Features

* Responsive single-page layout
* Skills and services showcase
* Technology stack section
* Contact form for project inquiries
* Email and WhatsApp quick contact options
